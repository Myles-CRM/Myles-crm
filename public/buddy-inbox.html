How it will work

Forward → Buddy reads → CRM helps

  1. You forward a useful email to Buddy's address.
  2. The email service sends it to the secure CRM webhook.
  3. The CRM saves it in Buddy Inbox so Buddy can review it before making notes, reminders, contacts, or calendar items.

Good things to forward

Buddy-friendly emails

  • Music lesson notes or practice tasks
  • Robotics links, instructions, or parts info
  • School event details and calendar updates
  • Homework reminders or project instructions
  • Emails you want summarised into the CRM

Do not forward

Stuff Buddy should not receive

  • Passwords, login links, or verification codes
  • Banking, payments, or private family documents
  • Anything Dad has not said is okay to share
  • Messages from someone who expects it to stay private

Buddy-controlled

Inbox first, Notes only when useful

Emails stay in the private Buddy Inbox until Buddy reviews them. Buddy can then choose to make a clean note, mark the email as reviewed, archive it, or use the details for a reminder.

  • No button that dumps every email into Notes.
  • No webhook token pasted into the public CRM page.
  • Notes are written deliberately by Buddy, not automatically copied from emails.

Setup checklist

Connected settings

  • SUPABASE_SERVICE_KEY — lets the server save private inbox messages.
  • RESEND_API_KEY — lets the server read the full forwarded email body.
  • BUDDY_INBOX_WEBHOOK_TOKEN — secret token to stop random posts.
  • BUDDY_INBOX_ACTION_TOKEN — separate private token so Buddy can review/file inbox messages.
  • BUDDY_INBOX_ALLOWED_TO — the Buddy email address allowed to receive.
  • Inbound email service/webhook pointed at /api/buddy-inbox with the webhook secret configured privately.
